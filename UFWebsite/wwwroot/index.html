Så funkar det

Hitta en match

1. Bläddra bland kommande matcher via lag, sport eller stad.

2. Välj match från tillängliga platser.

3. Köp biljetten och betala via Swish.

4. Ta emot biljetten via e-post samt mina sidor och visa upp den vid entrén.

Sälj din biljett

1. Logga in och koppla ditt säsongskort.

2. Välj den match som du inte kan gå på.

3. Lägg upp biljetten och sätt ett pris, aldrig över ordinarie pris.

4. Vänta på köpare och ta emot betalning via Swish.
